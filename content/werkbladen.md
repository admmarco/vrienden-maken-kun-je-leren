## Vriendschapsstijl {#stijltest}

Bij bijeenkomst 1. Zet een kruisje in de kolom die het best bij je past. Tel daarna per stijl je punten op: "klopt niet" = 0, "een beetje" = 1, "klopt" = 2.

| Uitspraak | Stijl | Klopt niet | Een beetje | Klopt |
|---|---|---|---|---|
| In een gesprek stel ik meer vragen dan dat ik over mezelf vertel. | L | | | |
| Mensen vertellen mij vaak persoonlijke dingen. | L | | | |
| Ik stel graag nieuwe activiteiten voor. | A | | | |
| Ik raak snel enthousiast over nieuwe mensen en plannen. | A | | | |
| Ik stel mensen graag aan elkaar voor. | V | | | |
| Ik voel me prettig in een groep. | V | | | |
| Als een vriend het moeilijk heeft, sta ik klaar. | S | | | |
| Ik heb liever een paar vrienden voor het leven dan veel kennissen. | S | | | |

**L** = luisteraar, **A** = avonturier, **V** = verbinder, **S** = steunpilaar. De stijl met de meeste punten is waarschijnlijk je voorkeursstijl. Kijk in [bijeenkomst 1](module-1.html) wat die stijl betekent.

## Conflictwerkblad {#conflict}

Bij bijeenkomst 7.

1. Waar ging het conflict over? (Zonder namen.)
2. Welke conflictstijl gebruikte ik? Doordrukken, toegeven, vermijden, compromis of samenwerken?
3. Welke stijl gebruikte de ander?
4. Wat ging goed?
5. Wat had beter gekund?
6. Wat had de ander eigenlijk nodig? En wat had ik nodig?
7. Welke stijl zou ik nu kiezen, en wat zou ik zeggen?

## Mijn konvooi {#konvooi}
